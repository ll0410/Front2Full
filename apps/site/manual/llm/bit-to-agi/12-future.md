# 第十二章：未来（AGI）

> 从 Chatbot 到 Agent、具身智能与世界模型——通向 AGI 的技术拼图与能力边界。

前面十一章把 LLM 从比特讲到训练、推理与工程部署。本章转向**应用形态与未来方向**：模型不再只「说话」，而是调用工具、操作电脑、驱动机器人、在内部维护世界模型（若想从零手写生产级 Coding Agent 并精读工业界源码，推荐配合阅读[《从 LLM 到 Agent》](https://daiw.org/manual/llm-to-agent)、[《Claude Code 实战手册》](https://daiw.org/manual/claude-code)、[《Codex CLI 实战手册》](https://daiw.org/manual/codex)与[《Codex CLI 源码精读》](https://daiw.org/manual/codex-source)）。这些能力叠加起来，常被称作通向 AGI 的路径——但每块拼图都有**可量化的上限**，本章会反复强调。

::: warning

AGI（通用人工智能）至今**没有公认定义，也没有系统通过严格验收**。下文讨论的是 2024–2026 年可见的工程进展与瓶颈，不是科幻预测。

:::
