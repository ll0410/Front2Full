## 适合谁

- 想搞懂 LLM 但不想先啃四年数学系的程序员
- 已经会用 API，想知道「模型里面到底发生了什么」的工程师
- 打算自己训模型、部署服务、做 Agent 的实践者

## 写作原则

1. **先比特，后 AI**——第一章完全不碰模型，先把「世界如何被计算机表示」讲透。
2. **代码优先**——能用十行 Python 或一张图说清楚的，不写公式堆砌。
3. **可跳转**——每篇独立成文，目录即知识地图。
