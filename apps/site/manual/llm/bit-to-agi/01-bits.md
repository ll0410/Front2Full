# 第一章：比特（Bit）

> 从 0 和 1 出发，理解数字、文件、内存与矩阵——AI 的物理底座。

这一章完全不讲 AI 模型本身，只讲一件事：**计算机里的一切，最后都是比特**。照片、语音、文字、程序、神经网络权重，在内存里看起来都一样——一长串 0 和 1。读完本章，你会用「字节数、带宽、误差」这些可量化的尺子，重新理解后面所有章节。
