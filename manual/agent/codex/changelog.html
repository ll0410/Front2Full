更新日志 ​

Codex CLI 近期稳定版（0.149 → 0.167.0）的新特性、行为变更与重要修复，整理自 GitHub Releases。

Codex CLI 的变更记录已经不写在仓库的 CHANGELOG.md 里——那个文件只有一句指向 GitHub Releases 的说明（偶尔在 Unreleased 小节里补记一两条修复）。本页整理近期的稳定版，只挑对 CLI 日常使用有影响的条目；某个版本完整的 PR 列表请看对应的发布页。

本手册基准版本：v0.167.0（2026-11-06 发布）。稳定版之间还夹着大量 rust-v0.x.y-alpha.N 预发布版本，本页不收录。查看本机版本用 codex --version，升级用 codex update（见安装、登录与升级）。

标记约定：🆕 新特性；⚠️ 行为变更（可能影响你现有的用法）；其余为修复与体验优化。

v0.167.0（2026-11-06） ​

  • 🆕 内嵌模式下的代理指挥中心与未读标记：支持通过 codex agents --no-daemon（以及内嵌会话中的 /agents）在不依赖共享后台服务的情况下打开代理指挥中心；代理指挥中心与会话选择器现在会标记包含未读结果的会话（见子代理与多 Agent 协作、会话管理）。
  • 🆕 终端会话选择器切换后端：可在会话选择器中直接切换已连接的对话后端，切换时保留当前输入框草稿（见会话管理）。
  • 🆕 本地图片附件预览与点击打开：在支持图形协议的终端中编写输入时即可预览本地图片附件，对话记录里查看过的本地图片路径也支持点击直接打开（见斜杠命令）。
  • 🆕 云厂商登录入口与 Vertex AI 向导：登录引导界面将 API Key 与云端模型提供方统一收纳到“Sign in another way”下；启用 features.gcp_setup_wizard = true 后可通过向导配置 Google Cloud Vertex AI（支持 Application Default Credentials 或服务账号凭据文件，见安装、登录与升级、模型与推理）。
  • 🆕 系统代理与补丁详情展开：/experimental 菜单新增“System proxy”（features.respect_system_proxy），允许 Codex 请求直接读取 macOS 或 Windows 系统代理设置；审批提示打开期间，可以直接在对话记录中展开补丁详情。
  • 🆕 托管网络约束与 prompt-user 命令规则：管理员配置支持在 [permissions.network] 下声明托管网络约束，并在命令规则中使用要求人工即时确认的 prompt-user 决策（见配置参数参考、命令审批规则）。
  • 🆕 插件应用设置与网关 OAuth 凭据存储：插件配置支持关联 app 设置；新增网关 OAuth 凭据的文件级持久化存储（见插件与组件包）。
  • 修复项：切换模型提供方后已保存的历史会话仍保持可见，遇到无法直接恢复的会话时可以阅读完整对话记录并生成可编辑的提示词到新会话中继续；Ctrl+L 清屏后仍可通过 Ctrl+T 查看此前消息；删字后露出句首 ! 时保持在普通对话草稿模式而不误切入 shell 模式；网络审批提示在对应请求结束时自动关闭，发往同一端点的并发请求逐一提示；长时语音（Realtime V3）会话在记录增长时分批将已完成的语音保存到对话历史；自动上下文压缩会正确计入失败响应保留的输出以及缺少 token 统计的响应。

完整变更见 v0.167.0。
