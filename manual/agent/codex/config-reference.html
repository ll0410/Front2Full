配置项速查 ​

按主题分组的常用 config.toml 配置项，列出键名、类型、默认值与作用（基于 Codex CLI v0.167.0）

本页挑出日常高频使用的配置项并按主题分组，键名、取值与默认值以 v0.167.0 源码为准。完整清单（含 MCP、插件、浏览器、遥测等数百项）见官方 Configuration Reference 与 JSON Schema；文件位置与优先级见配置文件。

表中“—”表示默认不设置；a.b 形式的键在文件里写作 [a] 表下的 b。

模型与推理 ​

键类型 / 取值默认作用
model字符串模型目录的默认模型默认使用的模型
review_model字符串当前会话模型/review 使用的模型
model_reasoning_effortlow、medium、high、xhigh、max、ultra 等模型默认推理强度，可用档位由模型决定；reasoning_effort_override（v0.163.0 起默认开启）允许请求超出目录预设列表的档位
plan_mode_reasoning_effort同上计划模式预设计划模式专用的推理强度
model_reasoning_summaryauto、concise、detailed、none模型默认推理摘要的详细程度；本地 TUI 新会话未设置时按 none 请求，TUI 状态行的实时推理摘要（v0.155.0 起）要设成其他值才会出现
model_verbositylow、medium、high模型默认回答详略
model_context_window整数模型默认上下文窗口 token 数
model_auto_compact_token_limit整数模型默认触发自动压缩的 token 阈值
model_post_turn_compact_threshold_percent整数 0～100—一轮结束后，上下文用量达到可用窗口的这个百分比就先压缩；省略或设为 0 表示不启用（v0.156.0 起）
service_tier字符串—服务档位，如 fast（即 priority）、ultrafast、flex、default
personalitynone、friendly、pragmatic—已弃用：v0.156.0 起 friendly、pragmatic 不再改变回复风格，/personality 也已移除；none 仍会去掉模型指令里的 Personality 小节
hide_agent_reasoning布尔false隐藏推理事件（TUI 与 codex exec）
show_raw_agent_reasoning布尔false显示模型输出的原始推理内容
model_catalog_json路径—启动时加载的自定义模型目录（v0.167.0 起取消了 1 MiB 文件大小上限）

模型提供方 ​

键类型 / 取值默认作用
model_provider字符串openai使用哪个提供方（内置支持 openai、amazon-bedrock、gcp、ollama、lmstudio 等）
openai_base_url字符串—改写内置 openai 提供方的地址（代理、数据驻留）
oss_providerollama、lmstudio—--oss 的默认本地提供方，未设时交互询问
model_providers.<id>.base_url字符串—提供方 API 地址
model_providers.<id>.env_key字符串—存放 API Key 的环境变量名
model_providers.<id>.wire_apiresponsesresponses协议，chat 已不再支持
model_providers.<id>.query_params表—追加到请求 URL 的查询参数
model_providers.<id>.http_headers表—固定请求头；env_http_headers 则从环境变量取值
model_providers.<id>.request_max_retries整数4HTTP 请求重试次数
model_providers.<id>.stream_max_retries整数5流式响应中断后的重连次数
model_providers.<id>.stream_idle_timeout_ms整数300000流式响应空闲超时（毫秒）
model_providers.<id>.requires_openai_auth布尔false使用 OpenAI 登录凭证
model_providers.<id>.auth.command字符串—通过外部命令获取 bearer token
model_providers.<id>.model_catalog_url字符串—Codex 格式模型目录的完整地址，获取时带上该提供方的认证、请求头与查询参数（v0.156.0 起；v0.167.0 起内置 openai 提供方也允许单独覆盖该项并取消了 1 MiB 大小限制）
model_providers.<id>.capabilities表（supports_remote_compaction、supports_turn_metadata_header、supports_web_search、supports_image_generation、supports_Parallel_tool_calls）依提供方而定显式声明自定义提供方支持的传输层能力（v0.165.0 起）
model_providers.<id>.gateway_oauth表（authorization_url、token_url、client_id、delivery、credentials_store 等）—提供方网关额外要求的 OAuth 凭据：浏览器登录后按 delivery 放进请求头或 cookie，与主认证一起发送；credentials_store 可选 auto、file、keyring（v0.156.0 起）
model_providers.amazon-bedrock.aws.profile字符串—AWS CLI 配置档名，配合 aws.region 使用
model_providers.amazon-bedrock.aws.credential_export表（command、args、timeout_ms）—用外部命令导出 Bedrock 签名所需的 AWS 凭据，timeout_ms 默认 30000，不能与 aws.profile 同用（v0.155.0 起）
model_providers.gcp.project_id字符串—Google Cloud Vertex AI 项目 ID（也可由 GOOGLE_CLOUD_PROJECT 提供，v0.165.0 起）
model_providers.gcp.location字符串globalVertex AI 区域或 global（也可由 GOOGLE_CLOUD_LOCATION 提供，v0.165.0 起）
model_providers.gcp.credential_file路径—显式指定 ADC 凭据 JSON 文件路径（也可由 GOOGLE_APPLICATION_CREDENTIALS 提供，v0.165.0 起）

审批与沙箱 ​

键类型 / 取值默认作用
approval_policyon-request、never、{ granular = { ... } }on-request何时暂停请求审批；untrusted 已不支持
approval_policy.granular.*布尔—sandbox_approval、rules、mcp_elicitations、request_permissions、skill_approval，为 false 的类别自动拒绝
approvals_revieweruser、auto_reviewuser审批请求交给谁审
auto_review.policy字符串—自动审查的本地策略，托管的 guardian_policy_config 优先
auto_review.extra_policy字符串—追加给自动审查的策略文本，托管的 guardian_extra_policy 优先（v0.157.0 起）
sandbox_moderead-only、workspace-write、danger-full-access见下方说明执行命令时的沙箱模式
sandbox_workspace_write.writable_roots路径数组[]额外的可写目录
sandbox_workspace_write.network_access布尔false允许沙箱内命令联网
sandbox_workspace_write.exclude_tmpdir_env_var布尔false不把 $TMPDIR 视为可写
sandbox_workspace_write.exclude_slash_tmp布尔false不把 /tmp 视为可写
default_permissions字符串—默认权限配置档（beta），如 :workspace
permissions.<name>.*表—自定义权限配置档，不可与 sandbox_mode 混用
allow_login_shell布尔true是否允许 shell 工具使用登录 shell
projects.<path>.trust_leveltrusted、untrusted—项目信任状态
windows.sandboxelevated、unelevated、mxc—原生 Windows 沙箱实现；mxc 使用微软的 MXC 容器，需要系统支持（v0.156.0 起）
web_searchdisabled、cached、indexed、livecached网页搜索模式，完全访问时默认为 live

sandbox_mode 未设置时：已有信任决定（trusted 或 untrusted）的目录默认 workspace-write，其余目录默认 read-only；原生 Windows 未配置沙箱时，workspace-write 会降为 read-only。原来的 windows.sandbox_private_desktop 已在 v0.156.0 移除，elevated 与 unelevated 沙箱一律在私有桌面上运行。

tool_output_token_limit整数—单个工具输出存入历史的 token 预算

MCP 服务器（摘要） ​

键类型 / 取值默认作用
mcp_servers.<id>.command字符串—stdio 服务器的启动命令（配合 args、env、cwd）
mcp_servers.<id>.url字符串—可流式 HTTP 服务器地址
mcp_servers.<id>.bearer_token_env_var字符串—从环境变量读取 bearer token
mcp_servers.<id>.enabled布尔—设为 false 可停用而不删除配置
mcp_servers.<id>.required布尔—为 true 时初始化失败会让启动失败
mcp_servers.<id>.startup_timeout_sec数字30启动超时（秒）；官方文档写作 10
mcp_servers.<id>.startup_readinessconnection、catalogconnection启动时是否必须等实时连接就绪；设为 catalog 时可先用有效的缓存工具清单把工具提供给模型，真正调用工具仍需实时连接。与 required = true 同用时，有效的缓存也算启动成功，连接失败要到调用工具时才报错（v0.158.0 起）
mcp_servers.<id>.tool_timeout_sec数字300单次工具调用超时（秒）；官方文档写作 60
mcp_servers.<id>.enabled_tools数组—工具白名单，另有黑名单 disabled_tools
mcp_servers.<id>.tool_input_schema_max_bytes整数（字节）5000单个工具的输入 schema 超过这个大小时逐步压缩（先删参数说明，再删定义等），调大可保留更多参数说明（v0.158.0 起）
mcp_servers.<id>.oauth.client_secret字符串—预注册 OAuth 客户端的密钥，换取令牌时使用，必须同时设置 oauth.client_id；也可用 codex mcp add --oauth-client-secret 写入（v0.158.0 起）

完整字段与用法见 MCP 集成。

otel.log_agent_responses布尔false把主代理与子代理的最终回复写入 OTLP 日志，只在 otel.exporter 为 otlp-http 或 otlp-grpc 时生效；内容可能敏感，每条上限为 64 KiB（v0.158.0 起）
otel.log_guardian_assessments布尔false把自动审查完成的评估（含理由）写入 OTLP 日志，生效条件同上，理由上限为 64 KiB（v0.158.0 起）

requirements.toml 常用键 ​

以下键只在管理员下发的 requirements.toml（或系统级 MDM / Windows 注册表策略）中有意义，用户与项目配置无法越过：

键作用
allowed_approval_policies允许的 approval_policy；列入 untrusted 表示允许不信任项目派生出的严格策略
allowed_approvals_reviewers允许的 approvals_reviewer
allowed_sandbox_modes允许的 sandbox_mode
allowed_permission_profiles允许的权限配置档，未列出的一律禁止
allowed_web_search_modes允许的 web_search 模式，disabled 始终允许
guardian_policy_config托管的自动审查策略，优先于本地 auto_review.policy
guardian_extra_policy托管的附加审查策略，优先于本地 auto_review.extra_policy（v0.157.0 起）
model_provider、model_providers强制选用的提供方，以及整体替换本地同名条目的提供方定义（v0.156.0 起）
features.<name>锁定某个功能开关的取值
permissions.filesystem.deny_read跨层级叠加禁止读取的路径或 glob 模式
permissions.network托管的网络权限约束（域名策略、Unix 套接字等，v0.165.0 起支持直接配置）
network_proxy托管的网络代理设置（v0.162.0 起）
rules.prefix_rules托管的命令前缀规则列表，取值可为 prompt、prompt-user（v0.167.0 起，即使开启自动审查也要求真人审批）或 forbidden
otel托管的 OpenTelemetry 遥测导出配置（v0.163.0 起）
windows.allowed_sandbox_implementations允许的原生 Windows 沙箱实现
models.new_thread.model新会话的托管默认模型，显式指定模型或推理强度时失效
