# 像素机甲射击小游戏 — 完整设定说明

本文档描述首页 hero 区域内嵌的像素风格机甲射击小游戏的完整设定，包括核心玩法、角色系统、数值参数、场景与特效、交互与生命周期。实现位于 [HeroGame.vue](../apps/site/.vitepress/theme/components/HeroGame.vue)，机甲素材位于 [mechSprites.ts](../apps/site/.vitepress/theme/components/mechSprites.ts)。

---

## 1. 游戏概述

这是一款轻量级的「高达 vs 渣古」像素射击小游戏，嵌入在站点首页 hero 区域作为互动装饰。玩家操控一台高达，跟随鼠标在画布内移动并自动射击，击落从顶部降落的渣古以积累变身次数，获取射速增益与额外子弹线。

**核心循环**：移动鼠标 → 自动射击 → 击落渣古 → 积累变身 → 变身强化 → 累计 5 次变身后触发全屏轰炸。

---

## 2. 核心玩法

| 项目 | 说明 |
| --- | --- |
| 操控方式 | 鼠标在画布内移动时高达缓动跟随；移出画布后高达**停留在最后跟随的位置**，不回到初始位置 |
| 射击 | 鼠标在画布内时持续自动射击，无需点击；每台高达有独立武器（见第 4.1 节）；重生期间不开火 |
| 目标 | 击落携带技术栈名词的渣古，避免与渣古相撞 |
| 胜负 | 无分数、无终点，纯休闲体验；相撞后高达原地复活，所有增益清零 |
| 全屏 | 鼠标在画布内跟随时**连按两次 F 键**切换全屏，ESC 或再次连按 F 退出（见第 9.5 节） |

### 2.1 初始提示

- 页面加载后底部显示提示文案「Try This Game · 连按 F 全屏」。
- 显示 **2 秒后自动隐藏**；若用户在 2 秒内移动鼠标，提示立即收起。

## 3. 角色系统

### 3.1 玩家机体（高达）

- **机体数量**：6 台，从像素参考图提取，各自保留原始配色与造型。
- **初始选择**：游戏开始时随机选用一台。
- **变身机制**：每击落 10 台渣古（`TRANSFORM_KILLS = 10`），高达在原地爆发一圈光芒并**随机切换**为另一台（不会与当前相同）。
- **子弹颜色**：跟随当前高达的主色（按像素出现频率统计，排除黑/白/低饱和灰）。

### 3.2 敌机（渣古）

- **机体数量**：3 台，随机出现。
- **出现方式**：从画布顶部外沿随机位置生成，向下移动并伴随正弦横摆。
- **生命值**：5 HP（`ENEMY_HP = 5`），被击中 5 次后爆炸。
- **携带标签**：每台渣古头顶显示一个随机技术栈名词（见第 7 节）。
- **同屏上限**：3 台（`MAX_ENEMIES = 3`），生成间隔 1.8~3.4 秒。

### 3.3 机体尺寸与响应式

高达与渣古的缩放系数根据画布高度动态计算，保证机体在不同尺寸容器中占据固定比例：

| 参数 | 高达 | 渣古 |
| --- | --- | --- |
| 目标占画布高度 | 24%（`PLAYER_HEIGHT_RATIO`） | 17%（`ENEMY_HEIGHT_RATIO`） |
| 缩放范围 | 0.3 ~ 0.9 | 0.22 ~ 0.7 |
| 参考 sprite 高度 | 48 px | 45 px |

## 4. 战斗数值

### 4.1 射击与武器系统

**基础参数**：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 基础射击间隔 | `FIRE_INTERVAL = 0.16s` | 初始约 6.25 发/秒 |
| 子弹速度基准 | `BULLET_SPEED = 46` 块/秒 | 各武器在此基础上调整 |
| 基础子弹数 | 2 颗 | 各武器不同 |
| 子弹线分布范围 | 机身宽度的 85%~90% | 随线数增加自动拉开间距 |

**6 台高达独有武器**：每台高达拥有完全不同的弹道形态、子弹外观与特殊行为，变身切换高达后武器即时切换。

| 高达 | 武器名 | 弹道形态 | 特殊行为 | 子弹外观 |
| --- | --- | --- | --- | --- |
| G0 经典 RX-78 | 散射光束 | 3~N 颗 ±8° 扇形 | 标准伤害 1 | 矩形光束 |
| G1 蓝白 | 穿透光束 | 2~N 道粗光束直射 | **穿透** 2 台渣古（每台只受 1 次伤害） | 带发光的长条光束 |
| G2 灰紫 | 反弹弹 | 4~N 颗 ±20° 扇形 | **撞左右墙反弹** 2 次 | 圆形弹 |
| G3 红甲 | 追踪弹（火箭） | 2~N 颗慢速弹 | **追踪**最近渣古，带拖尾 | 尖头火箭弹 + 尾焰拖尾 |
| G4 蓝重 | 双管重炮 | 2~N 颗两翼大型弹 | 伤害 **2**，体积大速度慢 | 大型矩形弹 |
| G5 青绿 | 三向射击 | 3~N 颗 ±30° 扇形 | 广覆盖直射 | 矩形光束 |

**射速加成整合**：射速加成（见 4.2）带来的额外子弹线对所有武器统一生效，在各自的角度/偏移模式上加密排列，保持弹道形态一致。

**子弹类型字段**：`Bullet` 携带 `vx/vy`（速度向量）、`color`、`w/h`（尺寸）、`pierce`（穿透次数）、`hitIds`（已命中敌人 id，防重复伤害）、`bounces`（反弹次数）、`homing`（追踪强度）、`damage`、`life/age`（寿命）、`shape`（rect/round/beam/rocket）、`trail`（拖尾）。

### 4.2 射速增益（变身系统）

每次变身带来以下增益，**累计线性叠加**：

- **射速加成**：每次变身 +15%（`FIRE_RATE_STEP`），封顶 +200%（`FIRE_RATE_MAX_BONUS`，即最快为初始的 3 倍）。
- **额外子弹线**：射速加成达到 **30% / 60% / 90%** 时各多一条子弹线（最多 5 条）。

| 变身次数 | 射速加成 | 子弹线数 |
| --- | --- | --- |
| 0 | 0% | 2 |
| 1 | 15% | 2 |
| 2 | 30% | 3 |
| 3 | 45% | 3 |
| 4 | 60% | 4 |
| 5 | 75% | 4 |
| 6 | 90% | 5 |
| 7+ | +90%（封顶） | 5 |

### 4.3 掉落机制

- 渣古被击落后有 **30% 概率**（`DROP_CHANCE`）掉落站点 logo。
- logo 以较慢速度下落并轻微横摆，高达碰到即「吃掉」，**立即触发一次变身**（同样累加射速加成与变身次数）。

### 4.4 碰撞与复活

- **高达撞渣古**：两台同时爆炸，不计入击落数、不掉落 logo。
- **复活延迟**：0.8 秒（`RESPAWN_DELAY`），期间高达不绘制、不开火。
- **无敌时间**：复活后 1.2 秒（`INVINCIBLE_TIME`），高达闪烁显示且不会再被撞毁。
- **增益清零**：相撞爆炸后 `transformCount` 归零，射速加成与额外子弹线全部重置。

## 5. 全屏轰炸

### 5.1 触发条件

**累计（非连续）变身次数达到 5 的整数倍**时触发一次全屏轰炸（`BOMBARD_TRANSFORM_COUNT = 5`）。即第 5、10、15… 次变身时各触发一次。

### 5.2 持续时间

**5 秒**（`BOMBARD_DURATION`）。

### 5.3 效果

轰炸期间：

1. **持续爆炸**：每 0.06~0.18 秒在画面 1~3 个随机位置触发爆炸特效。
2. **清屏**：清除所有在场敌机（不计入击落数、不掉落 logo）。
3. **视觉特效**（叠加在所有画面元素之上）：
   - **闪白**：开场 0.6 秒从全白衰减，之后以约 3.5Hz 脉冲式闪白。
   - **3 圈冲击波环**：从画面中心向外扩散，白/金/白三色错开相位。
   - **红色暗角 vignette**：径向渐变从中心透明到边缘暗红。当前通过 `BOMBARD_VIGNETTE = false` **关闭**（代码保留，改为 `true` 即可恢复）。

### 5.4 结束

持续时间结束后轰炸状态清除。若高达在轰炸期间被撞毁，轰炸状态也会随死亡一并清除。

## 6. 场景与背景

### 6.1 城市写字楼

画面背景由随机生成的**长方形城市写字楼**向下滚动，模拟场景前进的速度感。

| 参数 | 值 |
| --- | --- |
| 同屏数量 | 4 栋（`PROP_COUNT`） |
| 滚动速度 | 7 块/秒（`PROP_SPEED`，所有楼统一速度，无速度差） |
| 透明度 | 0.55（`PROP_ALPHA`） |
| 楼体宽度 | 10~21 块 |
| 楼体高度 | 12~27 块 |

#### 造型细节

- **顶部**：50% 概率加一根居中天线，楼顶带 1/3 宽的机房结构。
- **窗户**：两种风格随机出现：
  - **方格窗（grid）**：密集小方格阵列，每 4 列一根竖柱、每 3 行一道楼板。
  - **带状窗（strip）**：整排横向窗带交替黑色楼板。
- **窗灯**：窗户随机点亮（亮窗概率 75%~85%），模拟楼内零星开灯。

#### 主题适配

| 模式 | 楼体 | 亮窗 | 暗窗 |
| --- | --- | --- | --- |
| 深色 | `#1a1a1a`（近黑） | `#ffffff`（白） | `#444444` |
| 浅色 | `#c2c2c2`（浅灰） | `#3a3a3a`（深灰窗洞） | `#9a9a9a` |

深浅主题切换时自动重绘楼体。

#### 可破坏性

- 楼体有 **10 HP**（`BUILDING_HP`），子弹击中楼体时子弹消失、楼体掉血。
- 每命中一次，楼体被削掉一个角（左上 → 右上 → 右下 → 左下循环），缺口随命中次数增大。
- 打满 10 次后楼体爆炸，并立即在顶部补充一栋新楼。

### 6.2 建筑碰撞

- 楼体会**阻挡高达移动**，碰撞盒比楼体视觉每边缩小 1.5 块（`PROP_BLOCK_TOLERANCE`），避免贴边卡死。
- **分轴检测**：X 轴移动撞楼时只回退 X，Y 轴同理，因此高达可沿楼体侧面滑动。
- **被动推出**：若滚动的楼体把高达挤进楼体，沿最小穿透轴将高达推出，避免被卡死。

## 8. 视觉特效

### 8.1 爆炸特效

`explode(x, y)` 生成 16 个向四周飞散的像素粒子 + 中心白色闪光：

- 粒子颜色：黄 / 橙 / 红 / 白 循环（`EXPLOSION_COLORS`）。
- 粒子大小：1 或 2 块，28% 概率为 2 块。
- 生命周期：0.3~0.65 秒，带阻力衰减。

### 8.2 变身光芒

变身时以高达为中心四散 14 道放射光线（`RAY_COUNT`），持续 0.72 秒，伴随旋转。光芒颜色为当前高达的主色。

### 8.3 TRANS-AM 文字

变身时在高达位置弹出「TRANS-AM」文字：

- 红色发光填充 + 白色描边。
- 使用 `easeOutBack` 缓动先小后大带回弹。
- 前 40% 时间完成放大，停留后淡出。

### 8.4 行走动画

高达与渣古都有 4 帧行走动画（`WALK_FRAMES`），每帧时长 0.15 秒：

- 左右腿交替上抬 1 像素。
- 左右臂随步伐向外各多铺 1 列像素。
- 整体随步伐做正弦上下浮动（`BOB_AMPLITUDE = 0.25 块`）。
- 多台渣古的步频通过随机 `walkOffset` 错开，避免整齐划一地迈步。

### 8.5 全屏轰炸特效

见第 5.3 节。

## 9. 交互与生命周期

### 9.1 画布尺寸

- 内部以 **4px 为一个像素块**（`UNIT = 4`）绘制，保证像素风清晰。
- 缩放系数随容器尺寸变化，适配 hero 区域在桌面端（右侧面板）与移动端（标题上方）的不同尺寸。
- 高分屏通过 DPR（上限 2）保证清晰度，`imageSmoothingEnabled = false` 保持像素锐利。

### 9.2 主题适配

通过 `MutationObserver` 监听 `<html>` 的 class 变化（`dark` 类），切换时：

- 子弹颜色、logo 染色、楼体配色同步更新。
- 楼体渲染缓存清空，按新主题重绘。

### 9.3 性能优化

- 仅在画布进入视口且页面可见时运行 `requestAnimationFrame` 循环。
- 机甲的 4 帧行走图预渲染缓存（`walkFrames`），运行时直接 `drawImage`。
- 楼体 sprite 预渲染缓存（`propImages`），按楼体对象索引。
- 像素颜色按字符下标预解析为数字数组，渲染时省去逐像素查表。

### 9.4 事件处理

| 事件 | 行为 |
| --- | --- |
| `pointermove` / `pointerdown` | 更新指针位置，高达跟随，开始射击，隐藏提示 |
| `pointerleave` | 停止跟随，高达**停留在最后位置**，不再回到初始待机位 |
| 页面隐藏/切换标签 | 暂停游戏循环 |
| 画布离开视口 | 暂停游戏循环 |
| 主题切换 | 重算配色与楼体缓存 |
| 容器尺寸变化 | 重算画布尺寸与机体缩放 |

### 9.5 全屏运行

- **触发方式**：鼠标在画布内跟随状态下（`following === true`），**连按两次 F 键**（400ms 内）切换全屏。
- **退出方式**：再次连按两次 F，或按浏览器原生 **ESC** 键。
- **实现**：对 `.hero-game` 容器调用浏览器原生 Fullscreen API（`requestFullscreen()` / `exitFullscreen()`）。
- **自适应**：全屏进入/退出时容器尺寸变化，`ResizeObserver` 自动触发 `resize()`，画布分辨率与机体缩放即时重算，无需额外处理。
- **安全限制**：仅在鼠标跟随状态下响应 F 键，避免干扰页面其他输入；`requestFullscreen` 被浏览器拒绝时静默失败。
- **常量**：`FULLSCREEN_DOUBLE_TAP_MS = 400`（连按时间窗口，毫秒）。

## 11. 设定来源（项目工程约定）

以下规则已纳入项目工程约定，后续开发需遵循：

1. 渣古被击落后有 **30% 概率**掉落站点 logo，高达吃掉 logo 会立即触发一次变身。
2. 累计（非连续）变身次数达到 **5 次**后触发一次**全屏轰炸**，持续 **5 秒**。
3. 背景楼体为**随机大小与高度的长方形城市写字楼**，随深浅主题切换配色。
4. 楼体可被子弹击毁，每命中一次楼体缺一角，打满次数后爆炸并补充新楼。
5. 楼体阻挡高达移动，碰撞盒带 1.5 块容差，支持沿楼体滑动。
6. 6 台高达各拥有**独立武器**（散射/穿透/反弹/追踪火箭/重炮/三向），变身切换高达后武器即时切换。
7. 鼠标移出画布后高达**停留在最后跟随的位置**，不回到初始位置。
8. 全屏轰炸的红色暗角 vignette 当前**关闭**（`BOMBARD_VIGNETTE = false`），代码保留可恢复。
9. 鼠标跟随状态下**连按两次 F 键**切换全屏，ESC 退出，画布由 `ResizeObserver` 自动适配全屏分辨率。
